# 素材文件夹说明

把素材按下面的**文件名**放进对应子文件夹，游戏会自动检测并使用；**没有素材时游戏会优雅回退**（emoji + CSS + 合成音效），永远能玩。

> ⚠️ 授权要求：本项目**可能商用/发布**，所有素材必须为 **CC0 / 公有领域 / 明确可商用（无需署名）** 授权。放图前请确认授权，避免侵权风险。

## 总体格式要求

| 类型 | 格式 | 分辨率 | 大小限制 | 备注 |
|---|---|---|---|---|
| **背景音乐** | `.mp3`（首选）或 `.ogg`（备选） | 44.1kHz 立体声 | 单曲 ≤ 2MB（小游戏包体限制） | 30~120 秒无缝循环，≥128kbps（mp3）/ ≥96kbps（ogg） |
| **背景图** | `.png`（首选）或 `.jpg`（备选） | 1920×1080（横版） | 单张 ≤ 500KB | 暗色为佳，游戏文字是浅色 |
| **敌人/Boss 立绘** | `.png`（必须，需透明底或半透明） | 512×512 或 512×768（竖版） | 单张 ≤ 200KB | 透明底最佳，方便叠在暗色背景上 |
| **主角立绘** | `.png`（必须） | 400×600 或 512×768（竖版半身） | 单张 ≤ 200KB | 透明底最佳 |
| **卡牌插画** | `.png`（必须） | 256×256（方形）或 192×256（3:4 竖版） | 单张 ≤ 80KB | 卡牌空间小，细节不要太密 |
| **遗物图标** | `.png`（必须） | 128×128 或 256×256（方形） | 单张 ≤ 50KB | 图标要大色块、易识别 |

### 为什么有这些限制？
- **微信小游戏包体限制**：首包 ≤ 4MB，总包 ≤ 20MB。所有素材加起来控制在 10MB 以内。
- **抖音小游戏**：首包 ≤ 4MB，总包 ≤ 30MB。
- **卡牌插画 80KB/张**：47 张卡牌 ≈ 3.7MB，在可接受范围内。
- **BGM 2MB/首**：3 首 ≈ 6MB，建议用 `.ogg` 格式（同码率体积更小）。
- 如果素材太大，进 Cocos Creator 阶段可以再压，但**现在先按这个规格找**，避免后期重做。

### 素材总量预估
| 类型 | 数量 | 单件上限 | 合计上限 |
|---|---|---|---|
| BGM | 3 首 | 2MB | 6MB |
| 背景图 | 4 张 | 500KB | 2MB |
| 敌人立绘 | 34 张 | 200KB | 6.8MB |
| Boss 立绘 | 10 张 | 200KB | 2MB |
| 主角立绘 | 4 张 | 200KB | 0.8MB |
| 卡牌插画 | 47 张 | 80KB | 3.7MB |
| 遗物图标 | 12 张 | 50KB | 0.6MB |
| **合计** | **114 件** | — | **≈ 22MB**（超了，优先压敌人立绘和卡牌到一半大小） |

> 实际总量控制在 **10~15MB** 以内比较安全——敌人立绘可以降到 256×384（100KB/张），卡牌插画用 192×256（50KB/张），BGM 用 `.ogg` 96kbps 可以压到 1MB/首。

## 目录结构

```
素材/
├── music/    背景音乐（.mp3）
├── bg/       背景图（.png）
├── enemy/    敌人/Boss 立绘（.png）
├── hero/     主角立绘（.png）
├── card/     卡牌插画（.png）
└── relic/    遗物图标（.png）
```

## 1. 背景音乐 `music/`

文件名用 `.mp3`、`.ogg` 或 `.wav` 均可（游戏会按 `ogg → mp3 → wav` 顺序自动探测）。

**格式要求：** 44.1kHz 立体声，≥128kbps（mp3）/ ≥96kbps（ogg），30~120 秒无缝循环，单曲 ≤ 2MB。

| 文件名 | 用途 | 当前状态 |
|---|---|---|
| `bgm_menu.ogg` | 主菜单 / 开局 | ✅ 已提供（[OpenGameArt "Asianoriental2"](https://opengameart.org/content/asianoriental2)，CC0，作者 Tozan） |
| `bgm_map.ogg` | 爬塔地图 / 篝火 / 商店（探索） | ✅ 已提供（同 menu 曲目） |
| `bgm_battle.ogg` | 战斗 | ✅ 已提供（[OpenGameArt "Chipnese"](https://opengameart.org/content/chipnese)，CC0，作者 Spring Spring） |

- 建议替换：中式氛围（古筝/埙/箫/木鱼），循环无缝。直接覆盖同名文件即可。
- 缺失时回退为 Web Audio 合成氛围音。

## 快速开始

1. 按上表把素材文件放到对应子文件夹（文件名必须完全一致，全小写）。
2. 直接双击 `原型.html` 打开即可——有素材自动用素材，没素材自动回退。
3. 想验证回退态：临时重命名 `素材/` 文件夹，游戏照常运行。
