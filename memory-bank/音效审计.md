# 音效使用情况审计

## 〇、审计口径

- **地面真值来源**：`js/00_base.js`、`10_audio.js`、`20_data.js`、`30_engine.js`、`40_flow.js`、`50_ui.js`、`55_cloud.js`、`60_boot.js` 八个按固定顺序拼接的脚本（共享全局作用域）。`原型.html` 只提供 HTML/CSS，脚本以 `<script src="js/xx.js">` 外链引入，**无内联脚本**（已 grep 确认 0 处 `sfx(`/`playSample(`），故调用点一律以 `js/*.js` 为准。
- **三方对账**：
  - A 代码调用点 = 所有 `sfx('键'…`、`sfx("键"…`、`sfxOnce('键'…`、`playSample('键'…` 及通过变量/查表传来的键（已追到源头：`pickHitSfx`、`cardSfxFor→CARD_SFX`、`relicSfxFor→RELIC_SFX`、`bossSkillFx/bossSelfFx→BOSS_VFX` 槽位、`enemyGainHp` 的 `snd` 形参、`sfx('card_defense'|'block')` 三元、`sfx(__hk)`）。
  - B 合成表 = `js/10_audio.js::SFX_TABLE`（声明 122 键，见 `SFX_KEYS` 注释）。
  - C 磁盘素材 = `素材/sfx/` 共 **176** 个文件，按 `<键>_<take>.mp3`/`.wav` 剥离后缀得 **122** 个基础键。
- **外置采样 vs 合成兜底的决定逻辑**（`js/10_audio.js`）：
  - `sfx(name,opt)`（`10_audio.js:354`）先调 `playSample(name,rate)`（`:271`）。
  - `playSample` 只在 `SFX_BUF[name]` 已有预解码缓冲时返回 `true` → **播真的 mp3/wav**；预加载在 `loadSfxSamples()`（`:303`）里按 `sfxCandidates(name)`（`:239`：`sfx/<键>.<ext>`、`sfx/<键>_1.<ext>`、`_2`、`_3`）探测。
  - 若该键无采样（未放文件 / 探测失败 / file:// 下 fetch 被拦 / `sfxMode==='synth'`），`playSample` 返回 `false`，`sfx` 回退到 `SFX_TABLE[name]` 的合成步骤；**表里也没有该键**时走 `sfxWarnUnknown` 静默忽略（开发期 warn 一次）。
  - 结论：**键在 `SFX_TABLE` 里有定义只保证「有合成兜底」，要「真的播 mp3」必须 `素材/sfx/` 里存在同名文件。**
